# Aethera — AI Engineering Learning Tracker

> **Explore → Understand → Track**

Aethera is a visual-first learning tracker for exploring how AI systems work, from neural network foundations to inference, model adaptation, and evaluation.

Built to make a complex subject easier to navigate, Aethera brings visual resources, practical exercises, and reflection together in a guided learning journey. It encourages understanding at your own pace: explore a concept, try it, and explain what you learned.

## A clearer way to learn

- Follow a connected roadmap of **7 phases, 14 modules, and 31 topics**.
- Find learning resources, prerequisites, exercises, and understanding checks in each topic.
- Track study, understanding, and practical work separately.
- Save topics and resources, keep notes, and revisit questions.
- Back up browser-local progress and choose what to publish for read-only viewing.
- Learn on desktop or mobile with light and dark themes.

## Begin your journey

[Open Aethera on GitHub Pages](https://Abhi-lash19.github.io/AETHERA/) · [Read the user guide](docs/USER_GUIDE.md)

Aethera is a tracker, not a place where models run. Exercises take place in the linked resources or your own tools.

## Seven phases, one connected path

| Phase | What you will explore |
| --- | --- |
| **01 · Foundations** | Weights, activations, training, tokens and embeddings |
| **02 · Transformer** | Decoder blocks, attention, positions, feed-forward layers and generation |
| **03 · Inference** | Prefill, decoding, KV cache, context costs, latency and throughput |
| **04 · Hardware & local models** | CPU/GPU memory, bottlenecks, model selection, formats and quantization |
| **05 · Serving** | Batching, paged KV memory, inference runtimes and scheduling |
| **06 · Adaptation** | SFT data, LoRA/QLoRA, baseline comparisons and preference optimization |
| **07 · Evidence** | Quality evaluation, benchmarking, RAG, structured-output reliability and engineering decisions |

Explore freely, then enable browser-local tracking when you are ready. No account is needed. Public progress is a deliberately published snapshot, not automatic device sync.
